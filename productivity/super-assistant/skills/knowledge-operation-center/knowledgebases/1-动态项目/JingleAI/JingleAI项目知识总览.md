## 项目是什么

小叮当（JingleAI）是本次统一使用的项目名称，由用户于 2026-09-17 确认。`joy-desk` 是承载相关应用及共享包的 monorepo；代码中的 JoyDesk、JoyMobile、joyclaw 等名称可能分别代表历史名称、工程标识或产品版本，不能只按名字推断部署环境。

这套系统包含三个用户客户端、一个 Cloud 服务及管理界面、一个云端内核执行宿主。Cloud 同时服务多个客户端；Kernel Runner 提供云端 AI 执行。桌面端还具有本机 AI 执行和操作系统能力。

## 先建立的六个认识

1. **用户界面、业务控制、AI 执行分别定位。** Web 页面问题从 desk-web 查；成员权限或对话历史从 Cloud 查；云端沙箱执行从 Runner 查。
2. **Cloud 超出“后台管理网站”的范围。** 管理 UI 在 `apps/cloud/web`，Java 后端还承载对话、协作、权限、运行控制和自动化控制面。
3. **应用目录不等于技术栈。** 桌面主 UI 为 Vue；网页主 UI 为 React；移动端为 React Native/Expo；Cloud 后端为 Java；Runner 为 NestJS/TypeScript。
4. **共享内核不等于共享应用实现。** 应用访问内核只能走维护中的公开合同，不能跨目录导入内部 service 或共享内部单例。
5. **本地 JSONL 与 Cloud 权威有不同适用范围。** 本机内核记忆遵守 JSONL 单源；Cloud 接受并归一后的跨端对话遵守 Cloud 消息权威。详见 [[JingleAI跨端通信与数据权威]]。
6. **代码存在、文档宣称、线上验证是三类证据。** 本次只完成范围内的静态核对；旧 README 的版本、目录和默认环境已有明显漂移。
