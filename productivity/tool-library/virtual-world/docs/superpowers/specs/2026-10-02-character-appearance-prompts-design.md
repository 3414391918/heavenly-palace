# 新增角色形象与外部 Agent 提示词

## 已确认需求

用户提供完整流程；补充确认先选择参考角色，再选择该角色的一套形象。用户要求外部 Agent 直接按提示词保存结果，结果展示只需明确保存方式，不建设任务目录、自动导入器或后台生成队列。

新增形象弹窗先选择「形象制作」或「形象替换」，再选择当前作品中有图片的参考角色、带图片的参考形象，填写新名称。确认后通过现有 Core 档案保存流程创建当前角色的新形象，弹窗显示可复制的提示词。创建失败保留表单；取消不创建数据。未保存的基础资料先按现有离开确认处理，提示词使用最终保存的脸部身材描述。

## 提示词

制作模式参考所选资产的图片标签、构图、动作、角度和组织方式，建立当前角色的新形象。替换模式逐张对应参考资产，保持动作、角度、表情、构图和目标角色脸部一致，只替换服装及用户指定的发型等外观。参考资产来自其他角色时，身份以当前角色脸部身材描述为准；用户上传的形象参考只决定发型、服装，不用于替换目标角色的脸。

两种模式都预留一张或多张形象参考图及特殊说明的位置，都生成约 100 字发型描述、约 1000 字服装描述和全部新图片。提示词列出实际参考目录、所选形象 ID、每张图的标签与绝对路径，避免同目录中其他形象混入。新图片数量与选定参考资产对应，保留标签含义和组织规则。

## 保存与重新读取

提示词包含当前角色核心档案的绝对路径、新形象分区标记、图片目录和 assets.json 的绝对路径。外部 Agent 更新新形象分区中的描述，保留名称与分区标记；为新图片生成唯一 32 位小写十六进制 ID，文件名为 ID 加合法图片扩展名，在现有清单中追加带新形象 ID、标签及文件名的记录。保留其余档案字段、原有形象、原有清单记录和参考图片；先保存图片，再原子更新清单与文本。

返回角色页面时通过只读接口重新读取磁盘，展示新描述和图片；手工「重新读取」仍可使用。有未保存输入时沿用已有草稿保护，不自动覆盖。这里新增的是读取刷新，不自动生成或导入文件。

## 分层与验证

增加一个校验过的只读命令，Core 从已登记作品解析真实目录和参考资料，Renderer 不拼接作品目录。创建复用现有 saveCharacterProfile 事务及版本冲突保护。提示词与弹窗各自独立，沿用 PopupSelect、角色弹窗、主题变量和浮层反馈。

验证无图角色过滤、参考形象隔离、两种模式约束、真实输出路径、创建后重开、外部文本/清单/图片写入后重新读取、失败不留下已保存形象、陈旧版本保护、焦点刷新保留草稿，以及实际 Electron 弹窗和复制。保持现有构建预算与边界规则，不修改真实作品进行测试。
