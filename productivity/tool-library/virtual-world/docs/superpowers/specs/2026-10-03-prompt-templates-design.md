# 首页提示词模板

## 已确定的交互

小说空会话中的三个快捷按钮改成提示词模板。按钮仍显示模板名称，末尾追加“新增模板”。点击任一名称打开编辑窗口，包含模板名称单行文本框、模板内容多行文本框。底部依次为删除模板、使用模板、保存模板。新建窗口的删除按钮禁用。

保存只持久化模板，不发送消息、不改变聊天输入框。使用将当前编辑框的内容填入聊天输入框并关闭窗口，不自动发送、不自动保存。关闭窗口丢弃未保存的修改。删除已保存模板后立即更新列表；允许删除全部模板，列表仍保留新增入口。

## 存储与兼容

模板属于应用配置，所有小说共用。沿用 Main 的 LongAgentConfigStore 及配置文件，不写入小说、连续性账本或会话记录。模板记录包含 id、name、content。保留旧 welcomeShortcuts 文件字段作为兼容数据，首次读取缺少模板的旧配置时将三个快捷文本转换为初始模板的名称和内容。明确保存的空列表不能被默认值覆盖。

新增单条保存/删除命令，经 contracts、Preload、Main 校验。Main 在现有串行队列中读取最新配置并只更新目标模板，保留主智能体提示词和其它模板。普通智能体设置保存或重置保留模板。设置页移除旧快捷按钮编辑区。配置命令注册收口到 settings-command-schemas.ts，system.ts 保留系统协议与顶层注册，减少入口体量。

## 组件与验证

独立模板列表、编辑弹窗和 composable；通过 ConversationMessageList 的欢迎区插槽接入，资料库原快捷提问保持原交互。沿用主题变量、原按钮样式，名称列表自动换行，弹窗适配小窗口、支持 Escape 及焦点循环。保存失败保留编辑内容并显示浮层错误。

验证旧配置迁移、空列表持久化、单条并发更新、配置互不覆盖、校验失败保护原文件，以及创建、保存、使用、取消和删除交互。最终运行 pnpm verify，并检查实际页面。
