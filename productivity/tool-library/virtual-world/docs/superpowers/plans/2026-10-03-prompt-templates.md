# 首页提示词模板实施计划

**目标：** 将小说欢迎区改成可增删、可编辑、可填入输入框的提示词模板。

**实现：** 模板通过现有 longAgents 配置服务存储；独立组件经欢迎区插槽接入，使用仍走现有 suggestion 事件。

- [x] 添加配置存储回归：旧快捷文本迁移、空列表、并发单条更新、普通设置保存与重置保留模板。
- [x] 定义 PromptTemplateSchema、列表唯一 ID 校验和单条保存/删除命令，导出 Renderer 契约。
- [x] 扩展 LongAgentConfigStore 的串行配置更新；通过现有 settings IPC 和 Preload 暴露方法。
- [x] 添加模板编辑 composable 回归，覆盖保存与使用的区别、删除、新增和错误保护。
- [x] 实现列表与弹窗：两个文本框、三个底部按钮、关闭与焦点管理、主题与响应式布局。
- [x] 接入小说欢迎区；移除设置页旧快捷按钮编辑区。
- [x] 格式、类型、静态检查、完整测试和构建；重启并检查实际页面。
