# 删除角色形象

## 用户需求与交互

在角色核心档案的「新增形象」旁新增「删除形象」，对当前选中的已保存形象生效。没有形象或正在读写时禁用。点击前沿用未保存修改处理；确认框展示实际保存的形象名、待删除图片数量及「永久删除，不进入回收站，无法撤销」。取消、关闭、Escape 不执行删除；确认期间禁用按钮和关闭动作。成功后选中剩余第一套形象，允许删除最后一套。

## 文件与数据

Core 增加专用删除命令，以登记作品、角色 ID、形象 ID 定位文件。确认时捕获档案 revision 和该形象的图片 ID 清单；最新档案或图片集合不匹配则拒绝删除并提示重新读取。复用现有文件事务，原子更新核心档案、索引与作品更新时间，移除该形象图片清单记录并删除每张已登记图片的实际文件。事务成功后清理临时备份，不产生回收站记录。

角色的 assets 目录及 assets.json 是多个形象共用的，不删除其他形象的资料。没有剩余图片时删除空清单；图片目录为空时使用非递归 rmdir 清除目录。角色核心档案与关系文件仍由角色共用。未登记、无法归属所选形象的文件不做递归删除。删除路径必须在项目内部，拒绝符号链接、硬链接和不合法文件名。永久删除不生成旧全文迁移备份，并在同一事务清除该角色现有迁移备份；当前主档案保留其他形象与角色字段。若业务文件已成功删除、空目录清理因权限失败，则返回真实删除后的快照和警告，避免界面保留已不存在的数据。

## 分层与验证

contracts 定义严格输入，Preload 双向校验，Main 只转发给 Core，Renderer 只编排确认与显示。抽取现有档案写入操作构建函数，专用删除器复用更新逻辑。测试覆盖两套图片只删一套、最后一套目录清理、无图片形象、资料冲突与资产变化、错误路径和链接、失败不改变界面、取消不写盘及真实 Electron 删除后重开确认。
