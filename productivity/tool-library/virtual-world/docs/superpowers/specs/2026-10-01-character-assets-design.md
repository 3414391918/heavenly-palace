# 角色核心档案与图片资产

用户于 2026-10-01 确认开始开发。图片重命名直接修改图片标签，用于后续生图；界面不区分显示名称与固定身份。

## 界面

所有人物类型的核心档案使用表单。基础字段为角色名称、角色关键词、脸部身材描述、角色设定描述，每项有保存按钮。形象选择复用 PopupSelect；每个形象包含名称、文本描述、图片网格。支持新增形象。编辑形成临时草稿，点击保存后生效；切换时可保存、放弃或取消。

图片网格可滚动，批量上传复制源图片到作品目录。点击图片进入大图查看，支持缩放、拖动、复制原图。右键菜单包含重命名和删除，重命名修改图片标签，删除必须确认。支持 PNG、JPEG、WebP、GIF、AVIF；上传采用格式和大小校验。加载失败和操作结果使用浮层提示。遵守现有主题变量和字号设置。

## 文字与 Agent

核心档案 Markdown 继续作为文字唯一来源；表单解析、编辑并保存其固定分区。角色名称与别名沿用现有索引，关键词编辑同步可检索别名。文字保存通过 Core 事务同时更新文档和索引，携带版本防止覆盖较新的 Agent 修改。图片标签、清单与图片文件单独保存，不写进核心档案，不进入小说 Agent 上下文。

旧档案只读时解析展示，不因打开页面而改写。明确标记的脸部、体质设定和编号服装可拆分，不能确定归属的文字完整放入设定字段；首次保存前保留原文备份。Agent 对结构化文档的修改必须保留分区与形象标识，损坏结构的写入拒绝，错误明确提示。

## 分层

Contracts 定义跨进程的角色档案、图片与命令。Renderer 只管理界面和草稿。Main 选择上传文件、复制图片和提供受限图片协议。Core 是档案、图片及清单的唯一写入者。Preload 做输入和返回值校验。文本、图片清单和二进制操作复用项目事务；路径不得逃出登记作品，拒绝符号链接。原文图片引用保留。

## 验收

验证旧文无损迁移、独立字段保存、冲突保护、Agent 最新读取与审批写入、跨角色隔离、批量上传、标签保存、删除确认、大图缩放拖动复制、重启恢复及深浅主题。使用独立临时作品做写入测试。执行完整 pnpm verify，预算与边界检查保持现有标准。
