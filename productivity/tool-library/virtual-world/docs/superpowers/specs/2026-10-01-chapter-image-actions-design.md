# 正文预览图片复制与替换

## 用户操作

正文预览中的本地图片右键菜单只有「复制图片」「替换图片」。复制将图片像素写入系统剪贴板。替换打开模态窗口，支持 Command/Ctrl+V 或粘贴按钮，只接收一张图片，展示待替换图片，确认前不写盘。取消不产生修改。

## 保存与刷新

确认后通过 Core 原子覆盖章节 images 目录中的原图片，保持文件名、相对路径、图片格式、正文文本与索引不变。使用旧图片 SHA-256 检查并发修改，目标被改动后拒绝覆盖并提示重新打开。保存完成后给图片 URL 加内容版本，立即刷新同一预览内该图片的全部引用。切换章节关闭菜单和弹窗，不将异步结果用于新的章节。

## 边界

只允许已登记作品、索引中的章节正文明确引用的 images 单层文件名。拒绝路径穿越、软链接、硬链接、外部链接、超限文件和不可解码图片。Renderer 不访问文件系统；Preload 双向验证；Main 管理系统剪贴板；Core 排队、校验、转换图片格式并执行项目事务。PNG/JPEG/WebP/GIF/AVIF 均沿用原格式；剪贴板读取为单张静态图片，GIF 替换为单帧 GIF。

## 验证

验证取消、多图拒绝、复制、粘贴确认、即时刷新、同图多引用、保存后重新加载。存储测试验证正文和路径不变、格式正确、并发覆盖被拒绝、安全路径检查及失败后原图完整。真实小说不作为写入测试夹具。
