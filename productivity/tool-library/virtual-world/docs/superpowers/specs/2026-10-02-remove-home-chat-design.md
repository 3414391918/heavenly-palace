# 移除首页聊天功能

## 目标

移除首页侧栏的「聊天」及其独立浮窗。用户已明确要求删除该功能，且要求先提交并推送已有代码；前置提交 `678f00e` 已推送到 `origin/master`。

## 实现范围

- 删除侧栏导航项、打开事件、聊天专用的选中状态和主界面挂载。
- 删除专用的 Renderer 聊天组件、状态逻辑、样式及失去意义的功能测试。
- 删除按需加载注册与聊天导航类型，修正依赖这些旧组件的共享界面测试。
- 现有作品、角色资产和会话数据不发生写入；创作智能体复用的会话运行时及历史协议继续兼容。

## 验证

运行受影响的导航、共享对话和延迟加载测试，类型检查、范围格式检查与 ESLint、Renderer 边界和构建；确认产物不再包含独立聊天窗口入口。
