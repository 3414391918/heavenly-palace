# 新增角色形象提示词实施计划

**目标：** 用户创建新形象并复制制作或替换提示词，外部 Agent 按实际路径保存结果后，角色页面重新读取并展示。

**架构：** 增加只读参考资料命令；新形象保存复用现有 Core 事务。纯提示词构建、创建弹窗和焦点重新读取分别实现，无自动生成、自动导入或任务协议。

**技术栈：** Vue、Electron、TypeScript、Zod、Vitest。

## 执行步骤

1. 先为参考资料读取、提示词约束和形象保存失败编写行为测试，运行并确认功能缺失导致失败。
2. 在 contracts 定义参考资料输入和返回值，接入原有 Envelope、Main 路由、Core handler、Preload API；Core 使用登记目录和现有档案读取接口提供参考资料。
3. 独立实现提示词构建函数：制作/替换规则、用户参考图与特殊说明占位、约 100/1000 字描述、所选资产列表和本地保存协议。
4. 在现有档案 composable 增加命名形象保存，复用版本检查和草稿合并；独立弹窗实现模式、两级参考选择、新名称、确认创建、提示词复制。
5. 为当前角色页面加入返回窗口时的只读刷新，保持未保存草稿与选择；验证外部直接写入的描述、图片清单及图片能够重新展示。
6. 运行目标测试、类型检查、范围格式与 ESLint、边界检查、构建及临时作品 Electron 验证；独立审查协议和路径处理。更新本计划中的实际证据并恢复应用服务。
