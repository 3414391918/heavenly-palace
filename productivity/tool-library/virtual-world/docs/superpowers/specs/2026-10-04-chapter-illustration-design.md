# 正文编辑新增插画

## 交互

可编辑的章节正文右键菜单追加“新增插画”，保留原编辑与引用操作。点击后记录当前章节、正文草稿和光标位置，打开沿用图片替换样式的“新增图片”弹窗。支持粘贴一张图片，底部为取消和确认添加。确认成功关闭弹窗，正文显示独立段落的 `![](images/001.png)`，光标移到引用后，支持撤销正文引用。选中文字不会被删除，插入点为当前选择的末尾。

每章单独编号。扫描 images 目录已有数字图片名以及已保存正文和当前草稿中的图片引用，取最大编号加一，至少三位补零。空章从 001.png 开始；022.png 后为 023.png。不覆盖旧文件，不补用已占用编号；删除后的历史编号不另设清单。取消不创建文件。

## 保存

Renderer 经既有 contracts / Preload / Main / Core 链路提交图片、正文草稿、光标位置和已保存正文。Core 仅允许规范章节 body.md 的 images 路径，验证图片解码、大小与像素、章节身份和 UTF-8。已保存正文必须与磁盘一致；并在事务提交时再次校验正文、索引和清单。新增图片、插入后的正文、索引与清单一起提交。

并发占用同一编号时保留已有文件并重新分配编号；正文已被其它操作更新时拒绝添加且保留粘贴内容供重试。Renderer 将成功结果接入现有正文历史、已保存状态、恢复记录和书籍刷新流程，预览和重新打开使用已保存的相对路径。切换章节或锁定后旧菜单和弹窗操作失效，写入期间阻止同一编辑器的离开保存。

## 实现边界

复用原生文本菜单的校验协议，增加独立插画扩展，不影响文本引用扩展。新增独立插画编辑 composable、保存结果桥接 composable 和 Core 图片添加模块。把粘贴 UI 抽为共用弹窗，让新增与替换共享单图粘贴和主题样式。既有大入口只接线，图片写入留在 Core。

## 验证

测试从 001 开始、顺序递增、已有文件与缺失图片引用占位、正文草稿保留、准确插入、取消无写入、外部改写冲突、符号链接拒绝、坏图片不写入以及事务回滚。隔离 Electron 页面验证右键入口、粘贴、确认、撤销、预览和重开；运行完整 pnpm verify。真实小说和角色资产不作测试夹具。
